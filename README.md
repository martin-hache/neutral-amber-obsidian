# Neutral Amber

Tema claro y oscuro para Obsidian con grises neutros, sin matiz azulado, y acento ámbar.

## Paleta oscura

- Canvas: `#1c1c1c`
- Superficies: `#262626`
- Texto: `#ededed`
- Acento: `#f59e0b` / `rgb(245 158 11)`

## Paleta clara

- Canvas: `#f5f5f5`
- Superficies: `#ffffff`
- Texto: `#171717`
- Acento: `#f59e0b` / `rgb(245 158 11)`

## Instalación manual

1. Cierra Obsidian.
2. Copia la carpeta completa `Neutral Amber` dentro de `<tu-vault>/.obsidian/themes/`.
3. Abre Obsidian.
4. Ve a **Ajustes → Apariencia → Temas**.
5. Selecciona **Neutral Amber**.

Para alternar entre ambas variantes, cambia el **Esquema de color base** de Obsidian entre **Claro** y **Oscuro**.

La carpeta debe conservar exactamente el nombre `Neutral Amber` y contener, como mínimo, `manifest.json` y `theme.css`.

## Compatibilidad

- Modos claro y oscuro incluidos en el mismo tema.
- Versión mínima indicada: Obsidian 1.10.6.
- Creado con la estructura oficial de temas de Obsidian.
